# Broxer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A cross-platform default-browser shim that opens each clicked link in the browser chosen by domain rules, in ≤20 ms, plus an egui settings app that edits the rules file.

**Architecture:** Cargo workspace with four crates: `core` (config + matching, pure), `platform` (config path, launching, detection, notices), `router` (`broxer` binary, handles one link and exits), `settings` (`broxer-settings` egui binary + OS registration). The router never links GUI code.

**Tech Stack:** Rust 1.99, edition 2024; `serde`, `toml` 0.9, `url` 2, `dirs` 6; `winreg` 0.55 + `windows-sys` 0.60 (Windows); `objc2` 0.6 / `objc2-foundation` 0.3 / `objc2-app-kit` 0.3, `plist` 1, `core-foundation` 0.10 (macOS); `eframe` 0.32, `rfd` 0.15 (settings); `tempfile` 3 (tests).

**Spec:** `docs/superpowers/specs/2026-10-14-broxer-design.md` (read the Amendments section — it overrides earlier text).

## Global Constraints

- Platforms: Windows, macOS, Linux. Code for other OSes is `#[cfg]`-gated; CI must pass on all three.
- Router budget: median ≤20 ms from process start to exit (browser spawned) over 100 runs.
- Router dependencies: `serde`, `toml`, `url`, `dirs`, OS bindings only. No async runtime, no GUI crates.
- Release profile: `opt-level = 3`, `lto = true`, `codegen-units = 1`, `panic = "abort"`.
- Never open a link via "the default browser" (that is Broxer → infinite loop). Always launch a concrete executable; refuse to launch Broxer itself.
- Config path: `dirs::config_dir()/broxer/config.toml`, overridable with `BROXER_CONFIG`. Log: `broxer.log` next to the config.
- `BROXER_QUIET` set → no popups (log only).
- macOS bundle ids: router `dev.dmbsk.broxer`, settings `dev.dmbsk.broxer-settings`.
- `cargo clippy --workspace --all-targets -- -D warnings` must pass.
- Comments rare and short (user rule): only for non-obvious reasons.

## Review Focus

- Rule domains typed as URLs, wildcards, uppercase or IDN (`https://GitHub.com/`, `*.github.com`, `bücher.de`) must still match — tested in Task 1.
- Lookalike and userinfo hosts (`github.com.evil.com`, `https://github.com@evil.com`) must not match the rule — tested in Task 1.
- A config saved by Notepad with a UTF-8 BOM must still load — tested in Task 2.
- A browser entry that points at Broxer itself must never be launched (would loop) — tested in Tasks 3 and 5.
- URLs with `%`-escapes, `&`, `#`, quotes and spaces must reach the browser byte-identical — tested in Task 5.

```rust
pub fn normalize_domain(raw: &str) -> String {
    let mut domain = raw.trim();
    if let Some(i) = domain.find("://") {
        domain = &domain[i + 3..];
    }
    let domain = domain.trim_start_matches("*.").trim_start_matches('.');
    // Parsing as a URL lowercases, strips port/path and converts IDN to punycode like host_of does.
    match Url::parse(&format!("http://{domain}")) {
        Ok(url) => url.host_str().unwrap_or("").trim_end_matches('.').to_string(),
        Err(_) => String::new(),
    }
}

pub fn host_of(url: &str) -> Option<String> {
    let url = Url::parse(url.trim()).ok()?;
    if !matches!(url.scheme(), "http" | "https") {
        return None;
    }
    Some(url.host_str()?.trim_end_matches('.').to_string())
}

pub fn domain_matches(host: &str, domain: &str) -> bool {
    host == domain
        || (host.len() > domain.len()
            && host.ends_with(domain)
            && host.as_bytes()[host.len() - domain.len() - 1] == b'.')
}
```

```rust
    pub fn parse(text: &str) -> Result<Config, ConfigError> {
        // Notepad can save UTF-8 with a BOM, which the TOML parser rejects.
        let text = text.strip_prefix('\u{feff}').unwrap_or(text);
        let mut config: Config =
            toml::from_str(text).map_err(|e| ConfigError::Parse(e.to_string()))?;
        config.normalize();
        config.validate()?;
        Ok(config)
    }

    pub fn load(path: &Path) -> Result<Config, ConfigError> {
        match std::fs::read_to_string(path) {
            Ok(text) => Self::parse(&text),
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => Err(ConfigError::NotFound),
            Err(e) => Err(ConfigError::Io(e.to_string())),
        }
    }

    pub fn normalize(&mut self) {
        for rule in &mut self.rules {
            rule.domains = rule
                .domains
                .iter()
                .map(|d| normalize_domain(d))
                .filter(|d| !d.is_empty())
                .collect();
        }
    }

    pub fn validate(&self) -> Result<(), ConfigError> {
        if !self.browsers.contains_key(&self.fallback) {
            return Err(ConfigError::UnknownFallback(self.fallback.clone()));
        }
        for (i, rule) in self.rules.iter().enumerate() {
            if rule.domains.is_empty() {
                return Err(ConfigError::EmptyRule(i));
            }
            if !self.browsers.contains_key(&rule.browser) {
                return Err(ConfigError::UnknownBrowser { rule: i, browser: rule.browser.clone() });
            }
        }
        Ok(())
    }

    pub fn to_toml(&self) -> String {
        toml::to_string_pretty(self).expect("Config only holds strings, maps and lists")
    }

    pub fn save(&self, path: &Path) -> Result<(), ConfigError> {
        self.validate()?;
        let io = |e: std::io::Error| ConfigError::Io(e.to_string());
        if let Some(dir) = path.parent() {
            std::fs::create_dir_all(dir).map_err(io)?;
        }
        // Write-then-rename so a router starting mid-save never reads a half-written file.
        let tmp = path.with_extension("toml.tmp");
        std::fs::write(&tmp, self.to_toml()).map_err(io)?;
        std::fs::rename(&tmp, path).map_err(io)
    }

    pub fn browser_for(&self, url: &str) -> &str {
        host_of(url)
            .and_then(|host| {
                self.rules
                    .iter()
                    .find(|rule| rule.domains.iter().any(|d| domain_matches(&host, d)))
            })
            .map_or(self.fallback.as_str(), |rule| rule.browser.as_str())
    }
```

```rust
pub fn launch(browser: &Browser, url: &str) -> io::Result<()> {
    let path = Path::new(&browser.path);
    if is_broxer(path) {
        return Err(io::Error::other("refusing to open a link with Broxer itself"));
    }
    // Relative names (e.g. "firefox" from a Linux .desktop file) are resolved via PATH by spawn.
    if path.is_absolute() && !path.exists() {
        return Err(io::Error::new(
            io::ErrorKind::NotFound,
            format!("{} does not exist", browser.path),
        ));
    }
    command(path, &browser.args, url)
        .stdin(Stdio::null())
        .stdout(Stdio::null())
        .stderr(Stdio::null())
        .spawn()
        .map(drop)
}

pub fn is_broxer(path: &Path) -> bool {
    path.file_stem().is_some_and(|stem| stem.eq_ignore_ascii_case("broxer"))
        || path
            .components()
            .any(|c| c.as_os_str().eq_ignore_ascii_case("Broxer.app"))
}

#[cfg(target_os = "macos")]
fn command(path: &Path, args: &[String], url: &str) -> Command {
    if path.extension().is_some_and(|ext| ext == "app") {
        let mut command = Command::new("/usr/bin/open");
        command.arg("-a").arg(path).arg(url);
        if !args.is_empty() {
            command.arg("--args").args(args);
        }
        return command;
    }
    direct(path, args, url)
}

#[cfg(not(target_os = "macos"))]
fn command(path: &Path, args: &[String], url: &str) -> Command {
    direct(path, args, url)
}

fn direct(path: &Path, args: &[String], url: &str) -> Command {
    let mut command = Command::new(path);
    command.args(args).arg(url);
    command
```

```rust
pub fn installed_browsers() -> Vec<Detected> {
    let mut found: Vec<Detected> = Vec::new();
    for hive in [HKEY_CURRENT_USER, HKEY_LOCAL_MACHINE] {
        let Ok(clients) = RegKey::predef(hive).open_subkey(r"SOFTWARE\Clients\StartMenuInternet")
        else {
            continue;
        };
        for key_name in clients.enum_keys().flatten() {
            let Ok(key) = clients.open_subkey(&key_name) else { continue };
            let Ok(command) = key
                .open_subkey(r"shell\open\command")
                .and_then(|c| c.get_value::<String, _>(""))
            else {
                continue;
            };
            let Some(browser) = parse_command(&command) else { continue };
            if found.iter().any(|d| d.browser.path.eq_ignore_ascii_case(&browser.path)) {
                continue;
            }
            let name = key.get_value::<String, _>("").unwrap_or(key_name);
            found.push(Detected { name, browser });
        }
    }
    found
}

fn parse_command(command: &str) -> Option<Browser> {
    let command = command.trim();
    let path = match command.strip_prefix('"') {
        Some(rest) => rest.split('"').next()?,
        None => command.split_whitespace().next()?,
    };
    (!path.is_empty()).then(|| Browser { path: path.to_string(), args: vec![] })
}
```

```rust
pub fn installed_browsers() -> Vec<Detected> {
    let home = dirs::home_dir().unwrap_or_default();
    let data_home = std::env::var_os("XDG_DATA_HOME")
        .map(PathBuf::from)
        .unwrap_or_else(|| home.join(".local/share"));
    let data_dirs = std::env::var("XDG_DATA_DIRS")
        .unwrap_or_else(|_| "/usr/local/share:/usr/share".into());
    let dirs = std::iter::once(data_home).chain(data_dirs.split(':').map(PathBuf::from));

    let mut seen_files = HashSet::new();
    let mut found = Vec::new();
    for dir in dirs {
        let Ok(entries) = std::fs::read_dir(dir.join("applications")) else { continue };
        for entry in entries.flatten() {
            let file_name = entry.file_name();
            if !file_name.to_string_lossy().ends_with(".desktop") || !seen_files.insert(file_name) {
                continue;
            }
            if let Some(detected) = std::fs::read_to_string(entry.path())
                .ok()
                .and_then(|text| parse_desktop_entry(&text))
            {
                found.push(detected);
            }
        }
    }
    found
}

fn parse_desktop_entry(text: &str) -> Option<Detected> {
    let (mut in_main, mut hidden) = (false, false);
    let (mut name, mut exec, mut mime) = (None, None, String::new());
    for line in text.lines().map(str::trim) {
        if line.starts_with('[') {
            in_main = line == "[Desktop Entry]";
            continue;
        }
        let Some((key, value)) = line.split_once('=').filter(|_| in_main) else { continue };
        match key.trim() {
            "Name" => name = Some(value.trim().to_string()),
            "Exec" => exec = Some(value.trim().to_string()),
            "MimeType" => mime = value.to_string(),
            "NoDisplay" | "Hidden" => hidden |= value.trim() == "true",
            _ => {}
        }
    }
    if hidden || !mime.split(';').any(|m| m.trim() == "x-scheme-handler/https") {
        return None;
    }
    // Field codes (%u) and flatpak's @@ markers are placeholders, not arguments.
    let mut tokens: Vec<String> = exec?
        .split_whitespace()
        .filter(|t| !t.starts_with('%') && !t.starts_with("@@"))
        .map(|t| t.trim_matches('"').to_string())
        .collect();
    if tokens.is_empty() {
        return None;
    }
    let path = tokens.remove(0);
    Some(Detected { name: name?, browser: Browser { path, args: tokens } })
}
```

```rust
pub fn installed_browsers() -> Vec<Detected> {
    let mut roots = vec![PathBuf::from("/Applications")];
    if let Some(home) = dirs::home_dir() {
        roots.push(home.join("Applications"));
    }
    let mut found = Vec::new();
    for root in roots {
        let Ok(entries) = std::fs::read_dir(&root) else { continue };
        for entry in entries.flatten() {
            let app = entry.path();
            if app.extension().is_none_or(|ext| ext != "app") {
                continue;
            }
            if let Some(detected) = inspect(&app) {
                found.push(detected);
            }
        }
    }
    found
}

fn inspect(app: &Path) -> Option<Detected> {
    let info = Value::from_file(app.join("Contents/Info.plist")).ok()?;
    if !handles_https(&info) {
        return None;
    }
    let name = info
        .as_dictionary()
        .and_then(|d| d.get("CFBundleName"))
        .and_then(Value::as_string)
        .map(str::to_string)
        .or_else(|| app.file_stem().map(|s| s.to_string_lossy().into_owned()))?;
    Some(Detected {
        name,
        browser: Browser { path: app.display().to_string(), args: vec![] },
    })
}

fn handles_https(info: &Value) -> bool {
    info.as_dictionary()
        .and_then(|d| d.get("CFBundleURLTypes"))
        .and_then(Value::as_array)
        .into_iter()
        .flatten()
        .filter_map(|t| t.as_dictionary()?.get("CFBundleURLSchemes")?.as_array())
        .flatten()
        .any(|scheme| scheme.as_string() == Some("https"))
}
```

```rust
use std::path::Path;

use broxer_core::{Config, ConfigError};
use broxer_platform::detect::Detected;
use broxer_platform::launch::launch;
use broxer_platform::notice::report;

pub struct Context<'a> {
    pub config_path: &'a Path,
    pub detect: &'a dyn Fn() -> Vec<Detected>,
    pub popups: bool,
}

pub fn route(url: &str, ctx: &Context) {
    let log_dir = ctx.config_path.parent().unwrap_or(Path::new("."));
    let problem = match Config::load(ctx.config_path) {
        Ok(config) => match launch_from_config(&config, url) {
            Ok(None) => return,
            Ok(Some(warning)) => return report(log_dir, &warning, ctx.popups),
            Err(problem) => problem,
        },
        Err(ConfigError::NotFound) => format!(
            "no config at {}; open Broxer Settings to create one",
            ctx.config_path.display()
        ),
        Err(e) => e.to_string(),
    };
    let message = match (ctx.detect)().into_iter().find(|d| launch(&d.browser, url).is_ok()) {
        Some(d) => format!("{problem}\nOpened the link in {} instead.", d.name),
        None => format!("{problem}\nNo browser could be started for {url}"),
    };
    report(log_dir, &message, ctx.popups);
}

/// Ok(None): opened as configured. Ok(Some(warning)): opened in the fallback.
fn launch_from_config(config: &Config, url: &str) -> Result<Option<String>, String> {
    let name = config.browser_for(url);
    let error = match launch(&config.browsers[name], url) {
        Ok(()) => return Ok(None),
        Err(e) => format!("could not start browser '{name}': {e}"),
    };
    if name != config.fallback && launch(&config.browsers[&config.fallback], url).is_ok() {
        return Ok(Some(format!(
            "{error}\nOpened the link in fallback browser '{}' instead.",
            config.fallback
        )));
    }
    Err(error)
}
```

```rust
use std::time::Duration;

use objc2::rc::Retained;
use objc2::runtime::ProtocolObject;
use objc2::{MainThreadMarker, MainThreadOnly, define_class, msg_send};
use objc2_app_kit::{NSApplication, NSApplicationActivationPolicy, NSApplicationDelegate};
use objc2_foundation::{NSArray, NSObject, NSObjectProtocol, NSURL};

define_class!(
    #[unsafe(super(NSObject))]
    #[thread_kind = MainThreadOnly]
    #[name = "BroxerAppDelegate"]
    struct AppDelegate;

    unsafe impl NSObjectProtocol for AppDelegate {}

    unsafe impl NSApplicationDelegate for AppDelegate {
        #[unsafe(method(application:openURLs:))]
        fn open_urls(&self, app: &NSApplication, urls: &NSArray<NSURL>) {
            for url in urls.iter() {
                #[allow(unused_unsafe)]
                if let Some(text) = unsafe { url.absoluteString() } {
                    crate::route_url(&text.to_string());
                }
            }
            #[allow(unused_unsafe)]
            unsafe {
                app.terminate(None)
            };
        }
    }
);

impl AppDelegate {
    fn new(mtm: MainThreadMarker) -> Retained<Self> {
        let this = Self::alloc(mtm).set_ivars(());
        unsafe { msg_send![super(this), init] }
    }
}

pub fn run() {
    let mtm = MainThreadMarker::new().expect("router must start on the main thread");
    let app = NSApplication::sharedApplication(mtm);
    app.setActivationPolicy(NSApplicationActivationPolicy::Prohibited);
    let delegate = AppDelegate::new(mtm);
    app.setDelegate(Some(ProtocolObject::from_ref(&*delegate)));
    // Launched without a URL (e.g. double-clicked): show settings instead of idling forever.
    std::thread::spawn(|| {
        std::thread::sleep(Duration::from_secs(3));
        crate::open_settings();
        std::process::exit(0);
    });
    app.run();
}
```

```rust
impl Form {
    pub fn from_config(config: &Config) -> Form {
        Form {
            browsers: config
                .browsers
                .iter()
                .map(|(name, b)| BrowserRow {
                    name: name.clone(),
                    path: b.path.clone(),
                    args: join_args(&b.args),
                })
                .collect(),
            rules: config
                .rules
                .iter()
                .map(|r| RuleRow { domains: r.domains.join(", "), browser: r.browser.clone() })
                .collect(),
            fallback: config.fallback.clone(),
        }
    }

    pub fn from_detected(found: &[Detected]) -> Form {
        let mut form = Form::default();
        for d in found {
            let base = slug(&d.name);
            let mut name = base.clone();
            let mut n = 2;
            while form.browsers.iter().any(|b| b.name == name) {
                name = format!("{base}-{n}");
                n += 1;
            }
            form.browsers.push(BrowserRow {
                name,
                path: d.browser.path.clone(),
                args: join_args(&d.browser.args),
            });
        }
        form.fallback = form.browsers.first().map(|b| b.name.clone()).unwrap_or_default();
        form
    }

    pub fn to_config(&self) -> Result<Config, String> {
        let mut browsers = BTreeMap::new();
        for row in &self.browsers {
            let name = row.name.trim();
            if name.is_empty() {
                return Err("every browser needs a name".into());
            }
            if row.path.trim().is_empty() {
                return Err(format!("browser '{name}' needs a path"));
            }
            let browser = Browser { path: row.path.trim().to_string(), args: split_args(&row.args) };
            if browsers.insert(name.to_string(), browser).is_some() {
                return Err(format!("browser name '{name}' is used twice"));
            }
        }
        let rules = self
            .rules
            .iter()
            .map(|r| Rule {
                domains: r.domains.split(',').map(str::to_string).collect(),
                browser: r.browser.clone(),
            })
            .collect();
        let mut config = Config { fallback: self.fallback.clone(), browsers, rules };
        config.normalize();
        config.validate().map_err(|e| e.to_string())?;
        Ok(config)
    }

    pub fn move_rule(&mut self, index: usize, up: bool) {
        let other = if up { index.checked_sub(1) } else { Some(index + 1) };
        if let Some(other) = other.filter(|&o| o < self.rules.len()) {
            self.rules.swap(index, other);
        }
    }

    pub fn browser_names(&self) -> Vec<String> {
        self.browsers.iter().map(|b| b.name.trim().to_string()).collect()
    }
}

pub fn slug(name: &str) -> String {
    let mut out = String::new();
    for c in name.chars().flat_map(char::to_lowercase) {
        if c.is_ascii_alphanumeric() {
            out.push(c);
        } else if !out.is_empty() && !out.ends_with('-') {
            out.push('-');
        }
    }
    let out = out.trim_end_matches('-').to_string();
    if out.is_empty() { "browser".into() } else { out }
}

pub fn split_args(text: &str) -> Vec<String> {
    let (mut args, mut current) = (Vec::new(), String::new());
    let (mut quoted, mut started) = (false, false);
    for c in text.chars() {
        match c {
            '"' => {
                quoted = !quoted;
                started = true;
            }
            c if c.is_whitespace() && !quoted => {
                if started {
                    args.push(std::mem::take(&mut current));
                    started = false;
                }
            }
            c => {
                current.push(c);
                started = true;
            }
        }
    }
    if started {
        args.push(current);
    }
    args
}

pub fn join_args(args: &[String]) -> String {
    args.iter()
        .map(|a| {
            if a.is_empty() || a.contains(char::is_whitespace) {
                format!("\"{a}\"")
            } else {
                a.clone()
            }
        })
        .collect::<Vec<_>>()
        .join(" ")
}
```

- [ ] **Step 2: README** — `README.md`

````markdown
# Broxer

Opens every link you click in the browser your rules choose — e.g. YouTube in Zen, GitHub in Chrome. Broxer registers as your default browser, picks a browser in a few milliseconds and exits.

## Install

Build: `cargo build --release` (Rust 1.85+).

**Windows**
1. Copy `target/release/broxer.exe` and `broxer-settings.exe` to `%LOCALAPPDATA%\Programs\broxer\`.
2. Run `broxer-settings.exe`, set up rules, **Save**, **Register Broxer**.
3. Click **Open Default apps** and choose Broxer as the web browser.

**macOS**
1. `scripts/bundle-macos.sh`, then move `dist/Broxer.app` and `dist/Broxer Settings.app` to `/Applications`.
2. Open Broxer Settings, set up rules, **Save**, **Register Broxer**, confirm the macOS prompt.

**Linux**
1. Copy `target/release/broxer` and `broxer-settings` into the same directory (e.g. `~/.local/bin`).
2. Run `broxer-settings`, set up rules, **Save**, **Register Broxer** (sets the default via `xdg-settings`).

## Config

Broxer Settings edits this file; you can also edit it by hand (comments are lost when Settings saves).

| OS | Path |
|---|---|
| Windows | `%APPDATA%\broxer\config.toml` |
| macOS | `~/Library/Application Support/broxer/config.toml` |
| Linux | `~/.config/broxer/config.toml` |

```toml
fallback = "zen"

[browsers]
zen = { path = 'C:\Program Files\Zen Browser\zen.exe' }
chrome = { path = 'C:\Program Files\Google\Chrome\Application\chrome.exe' }
chrome-work = { path = 'C:\Program Files\Google\Chrome\Application\chrome.exe', args = ["--profile-directory=Profile 2"] }

[[rules]]
match = ["youtube.com", "youtu.be"]
browser = "zen"

[[rules]]
match = ["github.com"]
browser = "chrome"
```

- A domain matches itself and its subdomains (`github.com` matches `gist.github.com`, not `notgithub.com`).
- Rules are checked top to bottom; the first match wins. Unmatched links go to `fallback`.
- On macOS `path` may be an app bundle, e.g. `/Applications/Zen.app`.
- Problems (bad config, missing browser) are shown in a popup and written to `broxer.log` next to the config. The link still opens in the fallback or another installed browser.
- `BROXER_CONFIG` overrides the config path; `BROXER_QUIET=1` suppresses popups.

## Manual check (each OS)

1. Register Broxer and set it as the default browser.
2. From another app (chat, email, terminal), click a YouTube link → opens in Zen.
3. Click a GitHub link → opens in Chrome.
4. Click any other link → opens in the fallback.
5. Break the config (e.g. delete a browser referenced by a rule) → link still opens, a popup explains the problem.
````
